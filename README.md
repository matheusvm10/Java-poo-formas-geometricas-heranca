# Projeto Formas Geométricas - Herança e Polimorfismo em Java
## Atividade da matéria de Programação de Aplicativos
## DS-SENAI/BA

Este projeto demonstra a aplicação de **Herança** e **Polimorfismo** em Java através do cálculo de áreas e exibição de dados de diferentes formas geométricas.

## Tecnologias Utilizadas
- **Linguagem:** Java
- **IDE:** IntelliJ IDEA
- **Controlo de Versão:** Git & GitHub

## Conceitos de POO Aplicados
- **Herança (`extends`):** As classes `Retangulo` e `Circulo` herdam atributos e métodos da classe base `FormaGeometrica`.
- **Polimorfismo (`@Override`):** Sobrescrita do método `calcularArea()` para calcular a área específica de cada forma geométrica.
- **Tratamento de Objetos:** Execução dinâmica dos métodos sobrescritos ao percorrer uma estrutura de dados de formas.

## Como Executar
1. Clona este repositório: https://github.com/matheusvm10/Java-poo-formas-geometricas-heranca.git
2. Abre o projeto no IntelliJ IDEA.
3. Executa a classe `Main.java`.
